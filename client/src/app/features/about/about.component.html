About Crimen

Crimen is an interactive crime map for New York City, allowing users to explore crime data geographically and through historical trends.

Crime data spans from 2000 to 2013 and includes categories such as burglaries, murders, felony assaults, rapes, robberies, grand larcenies, and grand larcenies of motor vehicles.

Technology

  • Angular 19 with standalone components
  • Google Maps API with marker clustering
  • D3.js for interactive data visualizations
  • Node.js + Express backend
  • MongoDB + Mongoose
